# تحليل JavaScript في ReconHawk 1.7.2

هذا التحديث يعالج قصّ الحزم الكبيرة، وفقدان تعريفات الطلبات المصغّرة، وخطأ JSON
الناتج عن قص خرائط المصدر، وعدم وضوح اكتمال عمل المتخصص. لا يُشغّل كود JavaScript
المحمّل؛ التحليل ساكن، وطلبات الشبكة الخاصة به GET لملفات المصدر.

## ما الذي تغيّر؟

- تُقرأ الحزمة كاملة ضمن حد حجم واضح، بدلاً من أول 400 ألف حرف. الملف المتجاوز
  للحد يظهر كخطأ/تغطية جزئية؛ لا يُقدَّم أول جزء منه كتحليل مكتمل.
- تُتبع الاستيرادات النصية المدعومة وخريطة chunks الرقمية الشائعة في webpack.
  كل رابط مشتق يمر بحماية النطاق والتحويلات وDNS. لا يوسع وجود رابط في الكود نطاق الفحص.
- يربط محلّل AST المتغيرات المحلية، واستيرادات fetch/Axios المعروفة، وبعض عملاء
  webpack، والـwrappers المحلية، وتهيئة `fetchConfig`. يستخرج الطرق والحقول
  والترويسات الصريحة، ويحفظ callbacks وأدلة مستهلكي Redux عند إمكان ربطها.
- استنتاج ربط action creator باسمه أو تسجيل member يُعلَّم كاستنتاج يحتاج مراجعة.
  الشروط المجهولة والقيم الديناميكية تبقى تعابير رمزية. لا تُخترع توكنات أو بيانات مستخدم.
- عند وجود عدة صيغ لنفس endpoint تُحفظ variants؛ لا تضيع صيغة الجسم الثانية.
- خرائط المصدر تُقرأ كـJSON كامل. توجد معالجة للخرائط inline والأقسام المدمجة
  indexed؛ الأقسام الخارجية وغياب sourcesContent يُعرضان كنقص واضح.
- الأسماء `access_token` و`client_secret` لا تكفي لتنبيه تسريب. النتائج تعتمد
  أنماطاً وقرائن وتُعرض كمرشحات مقنّعة وغير متحققة. مفتاح Maps للمتصفح له تصنيف
  public_client_identifier؛ وجوده لا يثبت خللاً في القيود أو صلاحية المفتاح.

## الاستخدام والواجهة

ابدأ فحصاً جديداً أو استأنف الفحص بعد التحديث. يستطيع الوكيل استدعاء:

1. `analyze_js(url)` لقراءة الحزمة وchunks المدعومة، أو
   `analyze_js(url, include_chunks=false)` لملف واحد.
2. `analyze_source_map(url)` على رابط حزمة JS لاكتشاف خريطتها وتحليلها.
3. `list_analyses` للحصول على المعرفات وحالة التغطية.
4. `read_analysis(analysis_id, section, offset, limit)` لقراءة النتائج صفحة صفحة.
   تابع `next_offset` إلى أن تصبح null.
5. `read_file(path, offset, limit)` لقراءة المصادر والأدلة المحفوظة. الإزاحة بالبايت
   لتطابق `source_range`، والقراءة تحافظ على حدود UTF-8 بين الصفحات.

من الواجهة افتح **Assets → API request shapes**. تظهر manifests بتغطيتها وأعداد
الملفات والطلبات الرمزية، مع أزرار الملفات والأشكال والمسارات والمرشحات والتحذيرات.
توجد صفحة تالية عند الحاجة. في Overview، افتح المتخصص لقراءة تقريره وسبب توقفه.

مسارات API للقراءة:

```text
GET /api/tasks/{task_id}/analyses
GET /api/tasks/{task_id}/analyses/{analysis_id}?section=request_shapes&offset=0&limit=20
```

النتائج والمصادر في مساحة المهمة تحت `analysis/` و`srcmap/`. تحتفظ أسماء ملفات
المصدر ببصمة المحتوى، حتى لا يحل ملف جديد محل الدليل القديم عند تغير نفس URL.
لا تُرفع هذه الملفات تلقائياً إلى GitHub أو HackerOne.

## معنى التغطية

- `file_status=complete`: كل الملفات المكتشفة ضمن العملية قُرئت وحُللت ضمن الحدود.
- `resolution_status=partial`: بقيت قيم أو عقود رمزية تحتاج جلسة أو بيانات وقت تشغيل.
- `status=partial`: يوجد فشل أو حد أو رموز غير محسومة. قد تكون قراءة الملفات كاملة
  مع بقاء قيم الطلبات غير معروفة؛ هذان شيئان مختلفان.
- المتخصص يظهر partial عند انتهاء دوراته أو فشل أداة أو عدم وجود تحليل، وpaused
  عند التوقف. لا يحوّل وجود نص نهائي يقول «done» هذه الحالات إلى تحليل مكتمل.

الأدوات تحفظ النتائج الكاملة وتعيد ملخصاً صالحاً بصيغة JSON. بعض excerpts لها
علامة truncation وإحداثيات للمصدر الكامل. العنصر الضخم داخل صفحة النتائج له
`oversized_item` ومسار ملف كامل للقراءة؛ لا يُقص JSON إلى نص غير صالح.

الحدود الافتراضية: 16 MB لكل ملف JS، و48 MB إجمالاً، و12 ملفاً للعملية؛ 24 MB
للخريطة و2000 مصدر مدمج. يوجد حد لعقد AST والأشكال وعمق التتبّع. بلوغ أي حد مؤثر
يظهر كتغطية جزئية. التشغيل لا يجلب scripts الإعلانات والتحليلات الخارجية لمجرد
وجود روابطها كنصوص. زر Stop يمنع طلب ملفات لاحقة بعد انتهاء الطلب الجاري.

## المراجعة قبل إرسال طلب

التحليل الساكن لا يثبت أن endpoint يعمل أو أن الحقول إلزامية أو أن هناك ثغرة.
الترويسات المستخرجة تخص إعدادات الكود الصريحة؛ يمكن أن تضيف الجلسة أو المكتبة
قيماً أخرى. تتغير الأجسام أحياناً بدمج رد سابق من الخادم، وتبقى هذه الزيادة رمزية.

`probe_spec` يحتاج `confirm_shape` للأشكال المستنتجة أو متعددة الصيغ، وتزويد القيم
غير المحسومة صراحةً. طلبات الكتابة تحتاج أيضاً `confirm_write`. متخصص JS يملك
قراءة الملفات والنتائج، ويُمنع من إرسال طرق HTTP الخاصة بالكتابة أو تشغيل shell.

## حدود التتبّع

هذا محلل محدود ولا يحاكي JavaScript أو ينفذ bundles. الاستيرادات الديناميكية
المحسوبة، وتغييرات runtime/interceptors، وبعض أنظمة البناء والعملاء المخصصين،
وتدفقات cross-file المعقدة قد تبقى غير محسومة. الأسماء المتشابهة وحدها ليست
دليلاً أن دالة ما عميل HTTP. راجع نوع الدليل وموقعه قبل تفسير النتيجة.

رفع عدد دورات الوكيل قد يساعده يقرأ صفحات أكثر، لكنه لا يحول التعبير الديناميكي
إلى قيمة معلومة ولا يضمن اكتمال تغطية التطبيق.
